# 0.1.6.1 Repair2 — General Browser Scrolling

A narrowly scoped follow-up after persistent history and browser-context Repair1.

## Features
- User-authorized natural webpage scrolling in the active tab: up/down/top/bottom.
- Context-aware "show me more videos" only for a freshly verified active HTTPS YouTube results page.
- Read-after-write scroll verification; no execution claims from extension ACK alone.
- Extension rejects commands if active tab ID or exact URL has changed since Core examined it.
- Does not read personal contents, navigate, download, type, click, or modify the chat history DB.
- Consecutive scroll commands are allowed on separate spoken turns. Multi-step commands are not automatically split.
- Page scroll works on scrollable documents; nested custom scrolling surfaces may require later work.

## Install
1. Close Jarvis and extract ZIP into the project root.
2. `python .\apply_0_1_6_1_repair2_scrolling.py`
3. Reload Jarvis Browser Bridge in `edge://extensions` or `chrome://extensions`.
4. Run focused tests and full regression, then the desktop build.
5. Start Jarvis and perform live scrolling tests.

## New live tests
"Hey Jarvis"; "What is seventeen times twenty-three?" (391); "What planet is known as the Red Planet?" (Mars); "What is the capital of France?" (Paris); "Thanks Jarvis, that's all" (sleep).

Then wake again and say:
- "Open YouTube and search for Sidemen" -> results page.
- "Scroll down a bit" -> page moves down, not to a new video.
- "Keep going down" -> page moves further down.
- "Go back up" -> page moves up.
- "Jump to the bottom" -> page goes to document bottom.
- "Go back to the top" -> page goes to top.
- "Show me more videos" -> scrolls down on current YouTube results page; future semantic video discovery is separate.
- "Don't scroll down" -> no movement.
- "What if you scrolled down?" -> conversational reply; no movement.
- "Select the first video" -> same-tab watch page still works.
- "Pause the video" -> pauses. "Resume the video" -> resumes.

On a second normal public webpage, say "Scroll down" and "Scroll up". Verify both visually.

## Limitations
- Can't yet scroll arbitrary embedded nested panels independently of the document.
- "Show me more videos" scrolls the page; it doesn't yet inspect or recommend newly loaded results.
- A denied hypothetical could still trigger a tool proposal; Core denies and the conversation-layer recovery occurs. This is tracked separately.
- Browser extension must be reloaded after installing the service worker change.
