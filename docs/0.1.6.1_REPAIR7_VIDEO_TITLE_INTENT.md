# Jarvis Core v2 — 0.1.6.1 Repair7: verified natural video-title requests

## Why
Repair6 successfully selected an approximate-title match only when Mini happened to
propose the exact select_match operation and fully transcript-supported query.
Both typed and spoken "play the how far you can get video" were rejected with
unverified_user_intent, while "play the video titled How Far Can You Get" worked.
The logs do not expose the model-proposed tool arguments, so the exact failed
proposal cannot be proven from those logs alone; this repair covers common
and verified proposal mismatches and emits a sparse diagnostic line when repaired.

## What changed
- Mini guidance distinguishes choosing a new title-matched video from playing/resuming
  the active player. Only current-turn spoken words may describe the target title.
- The desktop browser session can reconcile a preexisting generic open/play or
  select_match proposal with a directly requested video title from confirmed,
  current-turn speech. The proposed title must overlap independent speech, not
  merely previous search context. Model query is replaced by the user's words.
- The existing Core gateway reauthorizes the resulting select_match and requires
  live active YouTube search results, validated video ID and link, a dominant
  text-only title match, same-tab navigation, and destination verification.
- Does not add a new client-side tool call, Google/YouTube shortcut, remote API,
  visual thumbnail recognition, prompt-independent auto-execution, or extra
  activity on ordinary chat turns. No changes to history, audio, or extension.

## Important limitations
This is guarded routing recovery for the existing model-selected browser operation,
not full generalized task planning. If Mini chooses no tool, no browser action occurs.
If the page doesn't contain a strong single title match, Jarvis must not guess.
The real Windows browser and model response remain to be tested.

## Install
Extract this archive into the current project root with Repair6 installed and
run `python .\apply_0_1_6_1_repair7_video_title_intent.py` with Jarvis closed.
Run the focused and full unit suites, desktop build, then Windows live checks.
Do not remove `.runtime/memory` or commit until live acceptance passes.
