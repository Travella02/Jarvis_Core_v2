# Jarvis Core v2 — 0.1.7.2: Isolated Background Browser Routing Repair

## Observed Windows failure
The user typed `Inspect the isolated background browser at example.org` with `JARVIS_TERRA_NAV_MODE=isolated_browser`. Mini proposed `browser_action` and Core rejected `unsafe_destination`. No Terra call was made. This is **not** an `.env` error.

## Fix
- Stronger Mini frontend + backend tool-selection guidance to distinguish the isolated browser from the user's foreground browser.
- A **read-only** Core recovery when a verified current-turn browser tool proposal unmistakably references an explicit inspection of the configured isolated browser. This always uses the configured Core URL, ignores model URL arguments, requires authenticated current-turn evidence and supported mode, and **cannot click/type** regardless of `JARVIS_TERRA_NAV_EXECUTE`.
- Read-only enforcement in `TerraNavigator.run()`; inspection cannot inherit normal execution or typing permissions.
- The model still chooses ordinary browser actions, app launch and non-inspection navigation normally; no unrestricted automatic action router.

## Install
Close Jarvis, extract into project root (currently 0.1.7.1), run:

```
python .\apply_0_1_7_2_isolated_routing.py
python -m unittest tests.unit.test_0_1_7_2_isolated_routing -v
python -m unittest discover -s tests\unit -p "test_*.py" -q
npm run desktop:build
python .\scripts\realtime_ab.py mini-overlap-luna-trim-guided-universal-apps
```

Expected offline: 994 tests run; 1 skipped. Leave `.env` at `JARVIS_TERRA_NAV_MODE=isolated_browser`, `JARVIS_TERRA_NAV_EXECUTE=0`, `JARVIS_TERRA_NAV_FOREGROUND_INPUT=0`, `JARVIS_TERRA_NAV_ALLOW_TYPING=0`, and configure approved example.org URL/hosts. Ensure Playwright + Chromium are already installed for the headless driver.

5. During any such test, user cursor and application focus remain unchanged.

## Limits
These checks run offline using stubbed Terra responses, not a Windows headless browser. Actual API/tool selection and Playwright setup remain to be verified in the user's Windows environment. The underlying Terra model call may still take several seconds. Do not commit before live verification.
