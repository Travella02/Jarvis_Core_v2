# Jarvis Core v2 — 0.1.7.3 Repair1: safe app-launch intent and concise page speech

Applies to **0.1.7.3**; keep `.runtime`, private `.env`, and `semantic_alpha_files`. This patch does NOT enable or change foreground injection and does not enable direct-link navigation.

## Fixes

1. **Core-owned launch veto:** A `launch_app` proposal cannot be executed when the independently authenticated user's words describe interaction with an already-open application instead of opening it. Example: `Play the file button in the open Notepad` must not spawn another Notepad. Also blocks `click`, `press`, `select`, `type`, `scroll`, etc., preceding a model-selected launch verb. Legitimate explicit launch requests retain their existing authorization process. The new veto is **not** a keyword-to-action router; it only prevents an already proposed launch from being authorized.
2. **Prompt guidance:** Both routing instructions emphasize that existing-app control does not mean app launch. Mini still decides which tool to propose; Core independently checks every action.
3. **Short observation narration:** For native isolated-browser inspection, Core retains the read-only bounded DOM observation for extracting facts, then produces a short speech string consisting of verified host, title, and the first substantive visible sentence. Avoids reading the full page and its additional languages. This is a bounded extract, **not an AI summary of the whole site**. It does not apply to Terra visual observations or make a new model call.
4. **`.env.example` parity:** Added `JARVIS_TERRA_BACKGROUND_NATIVE_INSPECT=1`, `JARVIS_TERRA_BACKGROUND_DIRECT_LINKS=0`, and `JARVIS_TERRA_BACKGROUND_IDLE_TTL=120`; private `.env` remains untouched.

### Standard five live voice phrases

1. `Hey Jarvis` — wakes with short response.
2. `What is seventeen times twenty-three?` — says 391.
3. `What planet is known as the Red Planet?` — says Mars.
4. `What is the capital of France?` — says Paris.
5. `Thanks Jarvis, that's all.` — sleeps.

### Follow-up checks (in isolated mode, EXECUTE=0)

1. `Inspect the isolated background browser at example.org.` — `navigate_app`, `observed_only`, short factual narration; no multi-language text dump. `model_ms=0` on native path.
2. Repeat immediately — `state=reused`, no browser startup, no Terra model call.
3. `Click the File menu in Notepad.` — `background_target_unverified`, no input injected.
4. `Play the file button in the open Notepad.` — must not call the OS launcher; Core must deny a model-selected `launch_app` or use the normal `navigate_app` denial for isolated mode. **No new Notepad window**.
5. `Open Discord.` — only here, if the user explicitly wants to launch Discord, should the existing app launcher be used (outside a game); ordinary launch intent remains supported.
6. `What if you clicked Exit in Notepad?` — no action.
7. `That's all, Jarvis.` — sleep.

Do NOT test inside active anti-cheat-protected games. This is an offline-verified patch; Windows tests and actual voice wording are still needed before committing.
