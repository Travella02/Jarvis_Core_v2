# 0.1.6.1 Repair3: natural scroll follow-ups and scoped pause

## Root causes established from the Oct 28 Windows logs
- "Jump to the bottom" omitted `jump` from Core action evidence.
- "Scroll down to the bottom" matched both relative `down` and absolute `bottom`.
- "Keep going" was classified as conversation, with no browser tool proposal.
- "Pause YouTube" sometimes generated `open` instead of `pause` and failed at destination validation.
- Two-step `pause ... and open ...` must not execute only a single site-opening effect.

## Behavior
- Natural absolute scrolling follows the confirmed user's destination even if Mini selected `down` or `open`; the existing extension verifies that the active page moved.
- Bare "keep going" can continue a scroll only if the model selects `scroll`, the previous turn successfully scrolled within 15 seconds, and a new extension snapshot verifies the exact same active tab and URL. No direct conversation output is overridden by Core.
- "Pause YouTube" can correct a misclassified model browser proposal, but requires confirmed user speech and a fresh active HTTPS YouTube watch-page snapshot. The worker is restricted to that exact active tab. Never falls back to a background video.
- Hypothetical, negated, multi-action, stale-tab, inactive-tab and mismatched operations remain blocked.
- History schema, local chat database, default Realtime voice path and permissions are unchanged.

## Install and validation
1. Close Jarvis and extract ZIP contents directly to project root.
2. `python .\apply_0_1_6_1_repair3_followups.py`
3. Reload the Jarvis Browser Bridge extension in Edge/Chrome (worker changed).
4. `python -m unittest tests.unit.test_0_1_6_1_repair3_browser_natural_followups -v`
5. `python -m unittest discover -s tests\unit -p "test_*.py" -q`
6. `npm run desktop:build`
7. Run the standard five voice tests, then scroll-down / keep-going / jump-bottom, direct pause and negative tests.

No installer cleanup or Git commit until Windows live tests pass. Do NOT remove `.runtime` or any user data.
