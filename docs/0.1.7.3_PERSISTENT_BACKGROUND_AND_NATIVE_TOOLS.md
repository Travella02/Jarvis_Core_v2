# Jarvis Core v2 0.1.7.3 — persistent isolated browser and native fast path

## Scope
Apply only on the committed **0.1.7.2** checkpoint. No deletion of `.env`, `.runtime`, virtual environment, conversation database, or any launch-app changes.

* Browser headless session is reused on **one private worker thread** across calls and wake/sleep. The Playwright sync API is never shared across worker threads.
* Isolated session state stays **in process memory** (never in the normal Chrome/Edge profile), closes when Core shuts down, and rotates at the next command after 120 seconds idle or 20 tasks. This is NOT a scheduled session-expiry timer.
* Read-only `Inspect the isolated background browser at example.org.` takes a **native DOM observation** rather than a Terra API call (default `JARVIS_TERRA_BACKGROUND_NATIVE_INSPECT=1`). This is faster in principle but a Windows benchmark is not yet available. The result contains the page title and bounded visible text, not visual understanding of images.
* Optional and **disabled by default**: `JARVIS_TERRA_BACKGROUND_DIRECT_LINKS=1` permits an exact uniquely matched, **quoted** link label on the configured background browser using same-host HTTPS browser-native navigation, only when `JARVIS_TERRA_NAV_EXECUTE=1`. External links, risky URL paths, query/fragment URLs, duplicate labels, out-of-scope actions, buttons, and foreground app actions fail closed. These conservative constraints cannot prove all GET requests are side-effect-free; test only on disposable public pages.
* Terra remains available when visual interpretation or an action not eligible for this narrowly scoped native fast path is needed. Core keeps its original action checks, screenshot feedback and budget limits.
* Foreground/immersive/game safety and existing app launching are unchanged. In isolated mode no OS mouse/keyboard injection is performed.
* Denial for a foreground Notepad task in isolated mode now explains that mode, rather than incorrectly talking about an unverified domain.
* New `[Jarvis Background Session] state=created/reused` log distinguishes browser startup from reuse; `[Jarvis Terra Timing]` continues to report `setup_ms`, `snapshot_ms`, `model_ms`, etc. No page content is written to those logs.

## Install
Close Jarvis. Extract 0.1.7.3 ZIP into the project root, then:
```
python .\apply_0_1_7_3_persistent_background.py
python -m unittest tests.unit.test_0_1_7_3_background_reuse -v
python -m unittest discover -s tests\unit -p "test_*.py" -q
npm run desktop:build
python .\scripts\realtime_ab.py mini-overlap-luna-trim-guided-universal-apps
```
Offline suite: 1002 tests run, 1 skipped. JS desktop build and live API behavior require Windows verification.

## Recommended .env for first live tests
```
JARVIS_TERRA_NAV_ENABLED=1
JARVIS_TERRA_NAV_MODE=isolated_browser
JARVIS_TERRA_NAV_EXECUTE=0
JARVIS_TERRA_NAV_FOREGROUND_INPUT=0
JARVIS_TERRA_NAV_ALLOW_TYPING=0
JARVIS_TERRA_BACKGROUND_URL=https://example.org/
JARVIS_TERRA_BACKGROUND_HOSTS=example.org
JARVIS_TERRA_BACKGROUND_NATIVE_INSPECT=1
JARVIS_TERRA_BACKGROUND_DIRECT_LINKS=0
JARVIS_TERRA_BACKGROUND_IDLE_TTL=120
```
Requires Playwright Python package and Chromium installed already as in 0.1.7.1. No new dependencies.

## Acceptance
Five standard voice tests: wake, 17 times 23 (391), Red Planet (Mars), France capital (Paris), sleep.

1. Type `Inspect the isolated background browser at example.org.`. Expect `navigate_app`, `observed_only`, `model_ms=0`, session `created`; real user desktop untouched.
2. Type the same request again quickly. Expect `state=reused`; `model_ms=0`; lower overhead ideally (not guaranteed).
3. Type `Click the File menu in Notepad.`. Expect `background_target_unverified`, zero actions, and a clear explanation that isolated mode cannot touch Notepad.
4. Type `What if we clicked an exit button on the background browser?`. Should not act.
5. OPTIONAL later, on a **disposable same-host HTTPS site with a safe unique link**, enable `JARVIS_TERRA_BACKGROUND_DIRECT_LINKS=1` but leave `JARVIS_TERRA_NAV_EXECUTE=0`; type `Click the "Exact Link Label" link in the background browser at approved.host.` and expect `preview_only`. Only after confirming page and destination are safe, toggle execute=1 and try the exact quoted link in disposable session. Other domains/duplicate/unsafe links must deny. `example.org` "Learn more" link is external and intentionally cannot be used for this test.

Do not enable physical foreground input for these tests. Do not run against signed-in or sensitive pages, or while testing anti-cheat-protected games. Do not commit until Windows acceptance passes.

## Limitations
This is a first background navigation building block, not a full general background desktop automation agent. The model can still take several seconds on visual paths. Browser session reuse is in-memory only and isolated site allowlist enforcement remains strict.
